# Forge H2 Enterprise 제품 방향

## 관찰

- Lovable의 핵심은 자연어로 제품을 만들고, 실제 코드·백엔드·배포까지 한 흐름에서 확인하는 것이다.
- Claude의 핵심은 프로젝트별 지식과 지침을 유지하고, 대화 옆의 편집 가능한 Artifact를 반복 개선하는 것이다.

## Forge H2 Enterprise에 적용할 원칙

1. **대화가 곧 작업 명세**: 사용자의 요청을 목표, 범위, 완료 조건으로 구조화한다.
2. **맥락은 프로젝트에 귀속**: 저장소 파일, 규칙, 메모, 기술 스택을 프로젝트 컨텍스트로 관리한다.
3. **결과는 채팅 밖에서도 사용 가능**: 코드·문서·미리보기를 Artifact로 분리하고 복사·다운로드·버전 비교를 지원한다.
4. **실행 가능한 신뢰**: 변경 전 계획과 diff를 보여주고, 테스트 결과를 함께 표시한다.
5. **배포까지의 짧은 루프**: Preview → Check → Publish를 명확하게 만든다.

## 현재 반영

- Forge H2 Enterprise 브랜딩과 온보딩
- 프로젝트별 최근 작업 저장
- 연결 상태 및 모델 표시
- 답변 복사와 빠른 작업 제안
- 로컬 우선 provider 구조

## 다음 제품 마일스톤

- 프로젝트 컨텍스트/지침 편집
- 저장소 파일 탐색과 안전한 diff 적용
- Artifact 미리보기 패널
- 테스트 실행과 오류 자동 수정 루프
- 공유 가능한 Preview 링크와 배포 로그
