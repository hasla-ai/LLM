# Forge H2 Enterprise: 수소발전소 전문 시스템

## 제품 정의

Forge H2 Enterprise는 수소발전소의 설계·안전·인허가·시공·운영 자료를 연결하고, 누락·충돌·위험을 찾아내는 엔지니어링 코파일럿이다.

최종 설계 승인이나 법적 책임을 AI가 대신하지 않는다. AI는 근거와 검토 대상을 제시하고, 자격 있는 전문가가 승인한다.

## 대상 범위

초기에는 수소를 연료전지 또는 수소터빈에 공급하는 발전시설을 대상으로 한다.

```text
수소 생산/공급
  → 압축·저장
  → 감압·조정
  → 연료전지 또는 수소터빈
  → 발전기·변압기·계통연계
  → 배기·열회수·냉각
```

## AI가 먼저 검토할 것

### 1. 수소 안전

- 누출 감지와 차단 구역
- 환기와 배기
- 방폭·점화원 관리
- 압력 방출과 피해 저감
- 배관·밸브·저장설비의 재료와 접합
- 비상정지와 화재 대응

### 2. 공정·설비

- 수소 공급 압력·순도·유량
- 압축기·저장용기·감압설비
- 연료전지 또는 수소터빈
- 냉각·열회수·배기
- 전기계통·보호계전·계통연계
- 계측제어·안전계장·통신

### 3. 인허가·검사

- 적용 법령과 KGS Code 식별
- 기술검토 및 허가 제출자료 목록
- 중간검사·완성검사 항목
- 안전관리규정과 교육 기록
- 설계 변경 시 영향평가

KGS Code는 가스 관계 법령의 시설·기술·검사 기준을 상세기준으로 코드화한 자료이므로, Forge H2 Enterprise는 답변마다 적용 코드와 조항의 출처를 함께 저장해야 한다.

## 전문 역할 맵

| 역할 | 검토 대상 |
|---|---|
| 수소·가스 안전 | 누출, 저장, 압력, 방폭, 사고 시나리오 |
| 기계·배관 | 압축기, 밸브, 배관, 재료, 응력 |
| 전기·발송배전 | 발전기, 변압기, 보호계전, 계통연계 |
| 계측제어 | 감지, 인터록, ESD, 안전계장 |
| 소방·방재 | 화재·폭발 감지, 소화, 대피 |
| 토목·건축 | 부지, 기초, 방호벽, 구조, 이격 |
| 환경 | 배출, 소음, 열, 수질, 온실가스 |
| 품질·안전 | 검사계획, 품질보증, 작업허가, 변경관리 |

## 제품의 첫 기능

1. 발전소 유형과 입력 자료 자동 분류
2. PFD/P&ID·설비목록·사양서에서 설비 추출
3. 설비별 위험·법규·검사 체크리스트 생성
4. 문서 간 압력·유량·재질·설비번호 불일치 탐지
5. HAZOP/What-if 회의 준비자료 생성
6. 누출·화재·비상정지 시나리오 정리
7. 근거 출처와 담당 전문가 검토 요청 생성

## 금지선

- AI 단독으로 안전거리·방출량·구조·보호설정값을 확정하지 않는다.
- 출처 없는 법규·KGS 기준을 사실처럼 생성하지 않는다.
- 검증되지 않은 설계값을 시공 문서로 내보내지 않는다.
- 모든 계산 결과에 입력값·단위·가정·검토자를 기록한다.

## MVP

첫 제품은 실제 발전소 설계를 자동 완성하는 시스템이 아니라, **수소발전소 설계 문서의 누락·충돌·안전 검토 항목을 찾아주는 시스템**으로 시작한다.
