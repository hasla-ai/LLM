# Forge H2 수소 계산 커널

문서 ID: FHZ-KERNEL-001
버전: 1.0.0
상태: 초안 — 기술개발 기준선

## 1. 무엇을 푸는가

스프레드시트와 일반 수치해석 도구는 숫자를 준다. 엔지니어링 산출물에 필요한 것은
**변호 가능한 숫자**다. 인허가 서류에 들어갈 수 없는 숫자는 프로젝트에서 값이 없다.

이 커널의 전제는 하나다. **계산과 근거사슬은 같은 객체여야 한다.**

모든 값은 다음 네 가지를 함께 들고 다닌다.

```
Quantity = (SI 수치, 8차원 벡터, 표준편차, 근거)
```

여기서 세 가지 성질이 따라 나온다.

1. **단위는 대수가 만든다.** `MW / (kWh/kg)` 는 `kg/h` 가 된다. 변환식을 쓰지 않는다.
   차원이 맞지 않는 덧셈은 경고가 아니라 오류다.
2. **근거는 하류로 전파된다.** 입력 하나가 가정(T5)이면 그 값을 쓴 모든 결과가 T5다.
   출처가 없는 값은 계산서 발행을 막는다. 엔지니어링 숫자에 대한 오염 추적이다.
3. **결과는 값이 아니라 분포다.** 불확실도가 붙은 입력을 흔들면 P10·P50·P90 이 나온다.
   대주단이 보는 것은 평균이 아니다.

## 2. 8개 기본차원

| 기호 | 뜻 |
|---|---|
| kg, m, s, A, K, mol, cd | SI 기본단위 |
| ₩ | 통화 |

통화를 차원으로 넣은 이유는 `원/kWh` 같은 값이 LCOE 계산에서 차원 검사를 받아야 하기
때문이다. 금액을 무차원으로 두면 단가와 총액을 더해도 아무도 막지 않는다.

## 3. 근거 등급

`schemas/evidence.schema.json` 의 `reliability_tier` 를 그대로 쓴다.

| 등급 | 뜻 | 예 |
|---|---|---|
| T0 | 관청·법령 확인 | 인허가 회신 공문, 정의값 |
| T1 | 기술기준 조항 | 판번호가 확인된 코드 |
| T2 | 시험성적서·실측 | 제3자 성능시험 성적서 |
| T3 | 벤더 자료 | 제안서 데이터시트 |
| T4 | 유도 계산·조사 | 검증된 계산서 |
| T5 | 가정 | 만료일이 붙은 잠정값 |
| — | 근거 없음 | 출처가 선언되지 않은 리터럴 |

결과의 등급은 기여한 모든 입력 중 **가장 나쁜 등급**이다. 하나가 무너지면 전부 내려간다.

### 리터럴 규칙

- 단위가 붙었거나, 비정수이거나, ± 가 붙은 리터럴은 출처를 요구한다.
- 정수 무차원 리터럴(`1`, `24`, `2`)은 수학 상수로 보아 등급을 내리지 않는다.
- 내장 함수는 자기 등급을 들고 다닌다. `lhv_h2()` 는 T4 이며, 발행기관과 판번호를
  붙여 T1 으로 승격하는 것이 정상 경로다.

## 4. 불확실도 전파

- 덧셈·뺄셈: 표준편차를 제곱합으로 합성
- 곱셈·나눗셈: 상대 표준편차를 제곱합으로 합성
- 거듭제곱: 상대 표준편차 × |지수|
- 내장 함수: 인자별 중심차분으로 수치 편미분

몬테카를로는 ± 가 붙은 모든 리터럴을 정규분포로 동시에 표본추출한다.
2,000회 시행이 브라우저에서 150 ms 안에 끝난다.

## 5. 문법

```
x = 20 [MW]                      값과 단위
x = 47.5 [%] ± 0.8               불확실도 (표준편차)
x = 7500 [원/kg] @T5 "출처"       근거등급과 출처
y = a / b as [kg/h]              표시 단위 지정. 차원이 다르면 거부
sweep(변수, 시작, 끝, 점수, 대상)   변수를 훑어 곡선 생성
mc(대상, 시행수)                   분포 생성
% 주석                            줄 끝까지
```

## 6. 구현

| 구성 | 위치 | 상태 |
|---|---|---|
| 워크벤치 (브라우저) | `app/static/h2-module.html` | 동작 |
| 공식 라이브러리 | `knowledge/formula-library-h2.json` | 18식, machine_checked |
| 검증 러너 | `tools/validate_formulas.py` | 동작 |
| 서버 계산 | `app/calc.py` | 동작 |
| 미션 실행 엔진 | `app/static/h2-mission-engine.html` | 동작 |

브라우저 커널과 `app/calc.py` 는 독립 구현이며 같은 입력에 같은 값을 낸다
(20 MW, η 47.5%, 소내부하 7.8% → 1,263.59 kg/h, 순출력 18.44 MW, 9,962 t/yr).
두 구현이 일치한다는 것 자체가 회귀 검사다.

## 7. 계산서

커널은 자격자가 서명할 수 있는 문서를 낸다.

1. 입력 — 값·단위·불확실도·등급·출처
2. 계산 — 식·결과·차원·등급
3. 불확실도 — P10/P50/P90
4. 근거 사슬 — 사용된 모든 출처
5. 서명 — 작성·검토·승인(유자격자)

계산 오류가 있거나 근거 미확보 항목이 남으면 **발행 불가**로 찍힌다.
최저 등급이 T5 이면 **조건부 — 가정 기반, 기준선 승격 불가**다.

## 8. 하지 않는 것

- **화염길이를 산출하지 않는다.** 누출률(FML-H2-014)까지만 낸다. 화염길이는 검증된
  상관식의 출처와 적용 유효범위, 그리고 자격자 판정이 있어야 한다.
- **안전거리·SIL·인허가 적합성을 판정하지 않는다.**
- **압축계수 Z 를 추정하지 않는다.** 실측표에서 근거와 함께 주어져야 한다.

계산이 맞다는 것과 설계가 맞다는 것은 다르다.
