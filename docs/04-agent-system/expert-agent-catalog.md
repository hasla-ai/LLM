# 수소발전소 전문가·자문 Agent 카탈로그

## 1. 범위와 주의사항

이 카탈로그는 대한민국에서 수소발전소를 기획·설계·건설·운영할 때 필요한 전문영역을 Agent 역할로 분해한 것이다.

`기술사 이상`은 해당 분야의 판단을 담당할 사람에게 기대하는 최소 전문성 기준이다. 실제 법정 선임자격, 설계·감리·검사·서명 요건은 시설 규모·압력·용도·관할·허가 조건에 따라 별도 확인한다. 아래 자격명은 Agent가 사람을 배정할 때의 후보 자격이며, AI에게 자격을 부여하는 표현이 아니다.

## 4. 대한민국 기준 확인 원칙

- 국가기술자격 종목과 현재 명칭은 [Q-Net 국가자격 종목별 상세정보](https://www.q-net.or.kr/crf005.do?id=crf00505)에서 프로젝트 시작 시점에 재확인한다.
- 자격명 예시는 Q-Net의 [전기응용기술사](https://www.q-net.or.kr/crf005.do?gId=&gSite=Q&id=crf00501&jmCd=0250&jmNm=%EC%A0%84%EA%B8%B0%EC%9D%91%EC%9A%A9%EA%B8%B0%EC%88%A0%EC%82%AC&jobSearch=N), [화공안전기술사](https://www.q-net.or.kr/crf005.do?gbnn=gbnSubtab2&id=crf00503&jmCd=0720&jmInfoDivCcd=B0), [건설안전기술사](https://www.q-net.or.kr/crf005.do?gId=&gSite=Q&gbnn=gbnSubtab2&id=crf00503&jmCd=0740&jmInfoDivCcd=B0), [건축구조기술사](https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=0490), [지질및지반기술사](https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=0825), [측량및지형공간정보기술사](https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=0680)에서 확인한다.
- 수소의 시설·기술·검사 기준은 [한국가스안전공사 KGS Code](https://www.kgs.or.kr/kgs/acde/view.do)와 시설별 적용 코드로 확인한다. KGS는 수소연료 사용시설, 수전해장치, 연료전지 등 대상별 코드를 구분한다.
- 수소연료공급시설과 수소 안전관리의 법적 범위는 [국가법령정보센터 수소경제 육성 및 수소 안전관리에 관한 법률](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1026016929)에서 확인한다.
- 이 문서의 자격 후보는 역할 배정용이며, 실제 허가·검사·감리·서명 요건을 확정하는 근거로 사용하지 않는다.
